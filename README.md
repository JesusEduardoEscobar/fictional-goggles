# Class Activities Repository

This repository contains all my class activities and assignments. It serves as a centralized location to organize, track, and showcase the work completed throughout the course.

## 📚 Purpose

This repository is designed to:
- Store and organize all class activities and assignments
- Track progress throughout the course
- Provide easy access to completed work
- Demonstrate learning outcomes and skill development

## 📁 Repository Structure

The repository will be organized as follows:

```
fictional-goggles/
├── README.md                 # This file
├── week-01/                  # Week 1 activities
├── week-02/                  # Week 2 activities
├── assignments/              # Major assignments
├── projects/                 # Course projects
├── resources/                # Additional learning resources
└── notes/                    # Class notes and documentation
```

## 🚀 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/JesusEduardoEscobar/fictional-goggles.git
   ```

2. **Navigate to specific activities:**
   - Browse folders by week or assignment type
   - Each folder contains relevant files and documentation

## 📋 Activity Categories

- **Weekly Activities**: Regular class exercises and practice problems
- **Assignments**: Graded assignments and homework
- **Projects**: Larger course projects and implementations
- **Notes**: Class notes, summaries, and reference materials
